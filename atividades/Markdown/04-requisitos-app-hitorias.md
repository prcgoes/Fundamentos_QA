## 1. Visão Geral do Sistema
O **Histórias Encantadas** é um aplicativo desenvolvido para o público familiar e infantil. Possui um acervo inédito de contos e fábulas gerados por Inteligência Artificial (IA), focando em acessibilidade e personalização da leitura.

---

## 2. Requisitos Funcionais (RF)

### 2.1 Instalação e Acesso
* **[RF01]** O aplicativo deve estar disponível para download em dispositivos móveis com sistema operacional **Android**.
* **[RF02]** Após o download, ao acionar o botão "Abrir", o app deve carregar a interface principal sem restrições de acesso imediato.

### 2.2 Página Inicial
* **[RF03]** O sistema deve permitir que o usuário realize buscas por títulos ou palavras-chave no campo de pesquisa.
* **[RF04]** O usuário deve poder classificar e marcar histórias como "Favoritas".
* **[RF05]** O sistema deve oferecer um filtro para exibir apenas as histórias favoritadas pelo usuário.
* **[RF06]** Por padrão, a tela inicial deve listar todo o acervo disponível de forma organizada.
* **[RF07]** As histórias devem ser categorizadas por gêneros (ex: "Contos", "Fábulas").

### 2.3 Visualização e Interação com Histórias
* **[RF08]** Ao selecionar uma história, o app deve exibir uma imagem ilustrativa no topo da página.
* **[RF09]** O texto completo da história deve ser exibido logo abaixo da imagem ilustrativa.
* **[RF10]** O sistema deve oferecer a opção de compartilhamento da história através de um ícone dedicado.
* **[RF11]** O ícone de compartilhamento deve estar localizado no cabeçalho da história.
* **[RF12]** O ícone de favorito (coração) deve estar visível no cabeçalho para acesso rápido.
* **[RF13]** Deve haver um ícone de "Configurações de Aparência" para ajuste de tamanho de fonte, tema (claro/escuro) e velocidade da narração.
* **[RF14]** O app deve disponibilizar o recurso **"Ler para Mim"**, utilizando narração via Inteligência Artificial.
* **[RF15]** O usuário deve poder pausar a narração do recurso "Ler para Mim" a qualquer momento.
* **[RF16]** O sistema deve permitir retomar a leitura exatamente do ponto onde foi pausada.
* **[RF17]** Deve haver um botão de navegação para retornar à tela inicial a partir de qualquer história.
